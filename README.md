# Menagerie Kernel

Menagerie Kernel is the kernel project within the Myriad OS ecosystem. This repository is dedicated exclusively to kernel development, including core architecture, memory management, process scheduling, hardware interfaces, interrupts, and kernel-level services.

It maintains its own source code, development workflow, tests, and roadmap, independently of the other ecosystem repositories. Designed to support Myriad OS and future integration with Orum.

## Related projects

- [Myriad OS](https://github.com/Redcherryman/Myriad-OS) — the operating system this kernel supports
- [Orum](https://github.com/Redcherryman/Orum) — the ecosystem programming language, future integration target
